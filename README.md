# MFA Under Siege — Interactive Security Training

A scenario-based, interactive MFA security training simulation built as a web application. Learners play as "Alex," an employee facing 3 escalating real-world MFA attack scenarios.

## Live Demo

[Try the Prototype](https://modexanderson.github.io/mfa-training/) | [View Design Document](https://modexanderson.github.io/mfa-training/design-document.html)

## Scenarios

1. **The Innocent Push** (Easy) — Unsolicited MFA notification
2. **The Pressure Play** (Medium) — MFA fatigue/push bombing + Slack social engineering
3. **The Social Engineer** (Hard) — Voice phishing from fake IT support

Each scenario is based on real breaches at Uber, Twilio, and Cisco.

## Features

- Branching decisions with 3 outcomes (wrong / partial / optimal)
- Timed decisions creating realistic pressure
- Realistic UI mockups (phone notifications, Slack, phone calls)
- Security score with animated feedback
- Real-world breach case studies after each scenario
- Personalized final report card
- Mobile responsive
- Zero dependencies — vanilla HTML/CSS/JS

## Running Locally

Open `index.html` in any browser. No build step required.
